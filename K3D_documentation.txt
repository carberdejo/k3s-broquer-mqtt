1. INSTALACIÓN DE K3S
=====================

Para instalar K3S (Kubernetes ligero):

curl -sfL https://get.k3s.io | sh -

Descripción: K3S es una distribución ligera de Kubernetes que es ideal para 
entornos edge, IoT y contenedores. Este comando descarga e instala 
automáticamente K3S en el sistema.

================================================================

2. CREACIÓN DEL CLUSTER
=======================

Para crear el cluster inicial con puertos específicos:

k3d cluster create frank-cluster --port "31883:31883@loadbalancer" --port "31001:31001@loadbalancer"

Descripción: Crea un nuevo cluster llamado "frank-cluster" con dos puertos 
expuestos:
- Puerto 31883: Puerto MQTT para comunicación con dispositivos IoT
- Puerto 31001: Puerto adicional para servicios específicos

================================================================

3. CONFIGURACIÓN DE PUERTOS ADICIONALES
=======================================

Para añadir nuevos puertos al cluster existente:

k3d cluster edit frank-cluster --port-add "32684:32684@loadbalancer"
k3d cluster edit frank-cluster --port-add "31883:31883@loadbalancer"
k3d cluster edit frank-cluster --port-add "31001:31001@loadbalancer"
k3d cluster edit frank-cluster --port-add "32017:32017@loadbalancer"

Para iniciar el cluster:

k3d cluster start frank-cluster

Descripción de puertos:
- 32684: Puerto para servicios adicionales
- 31883: Puerto MQTT (confirmación)
- 31001: Puerto de servicios (confirmación)
- 32017: Puerto para aplicaciones específicas

4. COMANDOS DE MONITOREO Y TROUBLESHOOTING
==========================================

4.1 Ver logs en tiempo real de Mosquitto:

kubectl exec -n frank-mqtt -it deployment/mosquitto -- tail -f /mosquitto/log/mosquitto.log

Descripción: Permite monitorear en tiempo real los logs del broker MQTT 
Mosquitto para detectar problemas de conectividad o errores.

4.2 Acceder al contenedor de Mosquitto:

kubectl exec -n frank-mqtt -it deployment/mosquitto -- /bin/sh

Descripción: Abre una shell interactiva dentro del contenedor de Mosquitto 
para realizar tareas de administración directa.

4.3 Listar pods activos:

kubectl get pods -n frank-mqtt

4.4 Acceder a un pod específico:

kubectl exec -n frank-mqtt -it <nombre-del-pod> -- /bin/sh

Descripción: Reemplazar <nombre-del-pod> con el nombre real del pod obtenido 
del comando anterior.

Introducción
============
Este documento describe el procedimiento para desplegar y administrar un cluster de Kubernetes con Mosquitto como broker MQTT, orientado a equipos de producción. Incluye los pasos desde la instalación de herramientas hasta la validación y recomendaciones finales.

================================================================

Herramientas Recomendadas
========================
- K3S (Kubernetes ligero)
- k3d (para clusters locales)
- kubectl (CLI de Kubernetes)
- Mosquitto (broker MQTT)
- Mosquitto_pub y Mosquitto_sub (para pruebas MQTT)
- Editor de texto (VS Code, nano, etc.)

================================================================

Requisitos Previos
==================
- Acceso a una máquina con Linux o WSL (Windows Subsystem for Linux)
- Permisos de administrador/root
- Conexión a internet
- Docker instalado (para k3d)
